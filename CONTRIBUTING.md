# Contributing to Typhon

Thank you for considering contributing to Typhon! We welcome bug reports, feature requests, documentation updates, and code contributions.

---

## 🛠️ How to Contribute

### Reporting Bugs
1. Search existing issues before opening a new one.
2. Provide OS version, .NET version, steps to reproduce, and actual vs expected behavior.

### Feature Requests
1. Explain the motivation for the feature and why it would benefit users.
2. Describe expected functionality clearly.

### Pull Requests
1. Fork repository and create a feature branch (`git checkout -b feature/amazing-feature`).
2. Follow existing VB.NET coding conventions and style.
3. Ensure solution builds cleanly without warnings (`dotnet build Typhon.sln`).
4. Commit changes with clear, descriptive commit messages.
5. Push branch and open a Pull Request.
